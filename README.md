# DSA Practice

A topic-based collection of standalone Java data-structures-and-algorithms exercises. 

## Layout

- `java/algorithms/sorting` — bubble, insertion, merge, quick, selection, and cyclic sort
- `java/arrays/basics` — array operations, swapping, maximum values, and multidimensional arrays
- `java/arrays/searching` — linear search and binary-search variants
- `java/arrays/leetcode` — LeetCode-style array problems
- `java/arrays/problems` — other array exercises
- `java/collections` — array lists and hash maps
- `java/data-structures/stacks-queues` — stack, queue, deque, and question notes
- `java/fundamentals` — Java basics and introductory number exercises
- `java/mathematics` — factorial, GCD, LCM, primes, digit problems, and Fibonacci
- `java/practice/misc` and `java/practice/tcs` — general and TCS-style practice questions
- `java/recursion` — recursion exercises and patterns
- `java/strings` — string and palindrome exercises
- `java/**/kunal-kushwaha` — categorized Kunal Kushwaha course assignments, retained with their original Git history
